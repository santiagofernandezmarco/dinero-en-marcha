# Tu dinero no puede estar quieto

Web divulgativa sobre por qué invertir a largo plazo frente a solo ahorrar, con datos reales:

- Contador de inflación en tiempo real (IPC España, INE).
- Comparativa a 30 años: cuenta de ahorro, oro, S&P 500 y una cartera diversificada 60/10/20/10.
- Caídas históricas (2008, 2020, 2022) y tiempo de recuperación.
- Simulador en JavaScript con aportaciones mensuales y ajuste por inflación.

**Ver la web:** https://santiagofernandezmarco.github.io/dinero-en-marcha/

## Estructura

- `index.html`: contenido de la página.
- `styles.css`: diseño y adaptación a móvil.
- `script.js`: contador de inflación, cálculo del interés compuesto, gráficos SVG y simulador.

Hecha con HTML, CSS y JavaScript, sin librerías externas. Desarrollada con apoyo de herramientas de IA generativa.
